THE BASICS

What Is Accessibility
in CSS?

Accessibility in CSS allows websites to respond to user preferences and create experiences that work for more people.

Features like prefers-color-scheme and prefers-reduced-motion allow designs to adapt automatically. This creates inclusive digital experiences for people with motion sensitivity, visual impairments, or cognitive differences.

→

By using these features, we can make the web more welcoming and usable for everyone, regardless of their abilities or preferences!

02

COLOR & CONTRAST

Make information
easy to see.

Color contrast affects how easily people can read and understand content.

Poor contrast
✕

Hard to read

Avoid similar colors that make text difficult to see.

Good contrast
✓

Easy to read

Use sufficient contrast between text and its background.

Quick tip

Dark text on light backgrounds and light text on dark backgrounds are usually easier to read.

03

MOTION

Let users decide
how things move.

Animation can make interfaces feel engaging, but excessive motion can be uncomfortable or distracting for some users.

@media (prefers-reduced-motion: reduce)
